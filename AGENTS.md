# Project instructions

Your main goal is to create a frontend UI with a modern user experience and connect it to the existing backend logic.

- Do not change backend code, the RAG pipeline, datasets, or the database.
- Build the UI around the existing backend interfaces and behavior.
- If integration requires a backend change, explain the requirement and ask the user before making that change.
- Use skills whenever useful, especially to avoid generic AI-generated design (AI slop).
